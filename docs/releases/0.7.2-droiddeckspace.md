# DroidDeckSpace 0.7.2

Runtime uninstall now removes the matching DroidSpaces container.

## Fix

Removing the Linux runtime used to delete only the app-side rootfs. The DroidDeckSpace container
stayed registered in DroidSpaces (stopped/invalid, pointing at a deleted rootfs).

`ContainerRuntime.removeContainers` now runs as part of the runtime removal:

- stops the container if it is still running (current name plus the legacy names used by earlier
  package ids);
- deletes the DroidSpaces container registry entry, logs and pidfile
  (`/data/local/Droidspaces/{Containers,Logs,Pids}/<name>`);
- cleans up any `droiddeck.com.droiddeck.*` leftovers from previous builds.

## Install

1. Install DroidSpaces, grant it root and open it once.
2. Install `DroidDeckSpace-0.7.2.apk`.
3. Grant DroidDeckSpace root in KernelSU/Magisk.
4. Open the app → Setup → Overview → install the Linux runtime → press Play.

Existing 0.7.1 installations get 0.7.2 through the stable update channel.
