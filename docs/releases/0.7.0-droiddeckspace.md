# DroidDeckSpace 0.7.0

First public release of the DroidDeck fork that runs the Linux runtime in a
[DroidSpaces](https://github.com/ravindu644/Droidspaces-OSS) container instead of proot.

## Highlights

- Full DroidDeck experience: Steam Gaming Mode, Linux desktop, stores, VR, glasses, overlays and
  the in-app Wayland compositor.
- Container runtime replaces proot: real namespaces, private `/dev`, host network, GPU nodes and
  bind mounts, all started and supervised by the app through root.
- Same official Linux runtime as upstream DroidDeck: installed from
  `Droid-Deck/DroidDeck-Components` and booted inside the DroidSpaces container automatically.
- Faster session startup (about 10–16 s; previously 65–80 s under KernelSU): one-time root bridge,
  ready-marker fast path, container/config cleanup.
- Desktop mode runs as the normal user `droiddeck` with `HOME=/home/droiddeck`; big-picture keeps
  `HOME=/root`.
- First-run guide in Setup → Overview for root access, DroidSpaces installation and runtime setup.
- Stable-only in-app updates from this repository.

## Install

1. Install DroidSpaces, grant it root and open it once (reboot if prompted).
2. Install `DroidDeckSpace-0.7.0.apk` from this release.
3. Grant DroidDeckSpace root in KernelSU/Magisk.
4. Open the app → Setup → Overview → install the Linux runtime → press Play.

`minSdk 26`, package id `com.droiddeckspace.launcher`. The APK is signed with the repository test
key (cannot be installed over an official DroidDeck build).

## Notes

- Requires root and DroidSpaces; upstream DroidDeck does not.
- Linux runtime updates follow the official DroidDeck runtime feed; app updates use the stable
  channel of this repository.
